# Original Peggle HD payload

This directory contains the original game payload used by the compatibility host. Account/purchase metadata, provisioning, and signing sidecars are excluded. Retained executable and asset bytes are unchanged; `payload-sha256.json` records them. The build reconstructs the nested IPA locally because the complete archive exceeds GitHub’s ordinary Git file limit.

This is original game content, not covered by the runtime’s open-source license. See ../LICENSE.md.
